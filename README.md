# Stōr - Smart Shopping List

Welcome to **Stōr**, your intelligent shopping companion that makes grocery shopping effortless and organized!

## 📱 About

Stōr is a beautifully designed shopping list app that helps you organize your shopping trips with smart categories, frequent item suggestions, and an intuitive interface.

## ✨ Features

### 📋 Multiple Shopping Lists
- **Unlimited Lists**: Create separate lists for different stores, occasions, or purposes
- **Independent Categories**: Each list has its own set of categories
- **Smart Learning per List**: Frequent items are tracked separately for each list
- **Quick Switching**: Easily switch between lists from the settings menu
- **List Management**: Create, rename, delete, and reorder your shopping lists

### 🗂️ Smart Categories
- **Custom Categories**: Create your own categories with custom names and colors for each list
- **Color-coded Organization**: Each category has its own distinctive color for easy visual recognition
- **Reorderable**: Drag and drop categories to arrange them in your preferred order
- **Collapsible Sections**: Expand or collapse categories to focus on what matters
- **List-Specific**: Each shopping list maintains its own unique set of categories

### 📝 Item Management
- **Quick Add**: Tap the floating + button to quickly add items
- **Smart Category Selection**: When adding uncategorized items, you're prompted to choose a category
- **Smart Suggestions**: Frequently added items appear as quick-add suggestions (per list)
- **Quantity Tracking**: Specify quantities for each item
- **Notes**: Add notes to remember specific brands or preferences
- **Category Memory**: The app remembers which category you use for each item in each list

### 🎯 Shopping Made Easy
- **Check Off Items**: Tap any item to mark it as shopped
- **Two View Modes**: Toggle between categorized view and simple list view
- **Swipe Actions**: Swipe left on items to quickly edit or remove
- **Batch Delete**: Remove all shopped items at once when you're done

### 🔄 Smart Learning
- **Frequent Items per List**: The app learns which items you buy regularly for each specific list
- **Auto-categorization**: Previously categorized items are automatically placed in the right category
- **Usage Counter**: Track how many times you've added each item to each list
- **Context-Aware Suggestions**: Suggestions are tailored to the list you're currently using

## 📖 Quick Start Guide

### Creating and Managing Lists

**Your first list:**
- The app starts with a default "Shopping List" with 10 pre-configured categories
- You can rename, customize, or delete this list at any time

**To create a new list:**
1. Tap the **gear icon** (⚙️) in the top left
2. Select **"Manage Lists"**
3. Tap the **+ icon** in the top right
4. Enter a name for your list
5. Tap "Save"
6. New lists start empty - add your own categories!

**To switch between lists:**
1. Tap the **gear icon** (⚙️) in the top left
2. Select the list you want to use (marked with a checkmark)

**To rename or delete a list:**
1. Go to **"Manage Lists"**
2. Tap a list or swipe left
3. Choose "Edit" or "Delete"
4. You must keep at least one list

### Adding Your First Item

1. **Tap the orange + button** at the bottom right of the screen
2. Type the item name in the search box
3. Tap the item pill or press enter to add it to your list
4. **If it's a new item without a category**, you'll be prompted to choose one
5. Select a category or tap "Skip" to leave it uncategorized
6. The item appears in your list

### Using Quick Suggestions

- When adding items, you'll see your **frequently added items** displayed as pills
- Simply **tap any pill** to instantly add that item to your list
- **Long-press a suggestion** for quick quantity options (1, 2, 3, or 4)

### Managing Items

**To check off an item:**
- Tap anywhere on the item to mark it as shopped
- Tap again to uncheck it

**To edit an item:**
- **Swipe left** on the item and tap "Edit", or
- **Tap and hold** the item for a moment

**In the edit screen you can:**
- Change the item name
- Adjust quantity using + and - buttons
- Change the category
- Add notes (brand preferences, size, etc.)

**To delete an item:**
- Swipe left on the item
- Tap "Remove"

### Working with Categories

**To manage categories:**
1. Tap the **gear icon** (⚙️) in the top left
2. Select **"Manage Categories"**
3. View all categories for the current list

**To create a new category:**
1. Open category management (gear icon → Manage Categories)
2. Tap the **+ icon** in the top right
3. Enter a name and choose a color
4. Tap "Save"
5. The category is added to your current list

**To edit a category:**
- **Tap any category** in the management list, or
- **Swipe left** and tap "Edit"
- Change the name or color
- Tap "Save"

**To delete a category:**
- **Swipe left** on the category
- Tap "Remove"
- All items in that category will become uncategorized

**To reorder categories:**
- Tap and hold the category
- Drag it to your preferred position

**Note:** Categories are specific to each list. Different lists can have completely different categories!

### View Modes

Switch between two viewing modes using the **segmented control** at the top:

**Categories View:**
- Items grouped by category
- Color-coded sections
- Collapsible groups
- Perfect for organized shopping

**List View:**
- Simple alphabetical list
- No category groupings
- Quick overview of all items

### Collapsing/Expanding Sections

**In Categories View:**
- Tap any **section header** to collapse or expand that category
- Tap the **chevron icon** in the top right to expand/collapse all sections at once

### Removing Shopped Items

After shopping:
1. Scroll to the **"Shopped" section** at the bottom
2. Tap **"Remove all shopped"**
3. All checked items are cleared from your list

## ❓ Frequently Asked Questions

**Q: Can I have multiple shopping lists?**
A: Yes! Create unlimited lists for different stores, occasions, or purposes. Each list is completely independent with its own categories and items.

**Q: Are categories shared between lists?**
A: No, each list has its own set of categories. This allows you to customize categories for different stores or purposes (e.g., grocery store vs. hardware store).

**Q: Do new lists come with default categories?**
A: No, new lists start empty. This gives you complete flexibility to create only the categories you need. The initial "Shopping List" comes with 10 default categories to help you get started.

**Q: Can I sync my lists between devices?**
A: Currently, Stōr stores data locally on your device. Cloud sync is planned for a future update.

**Q: Can I share my list with family members?**
A: List sharing is not currently available but is on our roadmap for future releases.

**Q: How do I backup my data?**
A: Your data is included in your device's iCloud backup if you have that enabled.

**Q: Why are different items suggested for different lists?**
A: Each list learns independently. Frequent items are tracked per list, so your grocery list suggestions won't appear in your hardware store list.

**Q: Can I skip categorizing an item?**
A: Yes! When prompted to select a category, you can tap "Skip" to leave the item uncategorized. You can always categorize it later by editing the item.
